# IT313 JavaScript ES6+ Essentials

## Problem

The Enrollment Eligibility Checker calculates the average of each enrollee's prelim, midterm, and final grades. A student is PASSING if the average is 75 or higher. Otherwise, the student is on PROBATION.

## Approach

The program uses modern JavaScript ES6+ features including const, arrow functions, destructuring, map(), filter(), reduce(), template literals, ES modules, Promises, async/await, and try/catch.

The gradeUtils.js file contains the computeAverage() named export and isPassing() default export. The main.js file processes the enrollee data and generates the eligibility report.

## How to Run

Make sure Node.js is installed.

Run the main script using:

```bash
node main.js
